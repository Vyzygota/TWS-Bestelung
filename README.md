# TWS Laundry Order System 🧺

**🇩🇪 Deutsch**  
Eine reaktionsschnelle, mehrsprachige (DE, EN, PL) Webanwendung für die Bestellung von Hotel- und Gastronomiewäsche bei TWS Rügen.  
Das System bietet eine moderne Benutzeroberfläche, eine intelligente Berechnung des Lieferdatums (mit einem 2-Tage-Puffer, der Wochenenden und gesetzliche Feiertage in Mecklenburg-Vorpommern überspringt) und eine nahtlose Integration mit Google Sheets als Backend. Es generiert automatisierte E-Mails für das Lager und den Kunden und überträgt die Bestelldaten direkt in die dynamischen Produktionsberichte.

**🇬🇧 English**  
A responsive, multilingual (DE, EN, PL) web application for ordering hotel and restaurant laundry from TWS Rügen.   
The system features a modern user interface, smart delivery date calculation (with a 2-day buffer that skips weekends and German public holidays in MV), and seamless integration with Google Sheets as a backend. It generates automated emails for both the warehouse and the client, while instantly syncing order data into dynamic production reports.
